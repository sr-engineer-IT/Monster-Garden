# AI Image Prompts - Monster Garden

Paste each prompt into an image AI. Save the result in `Resources/Images` using the file name shown
(for example `rabbit.png`). Then upload the image to an image-to-3D tool (Meshy, Tripo) and save the
3D model in `Resources/Models` with the same name (for example `rabbit.fbx`).

## Style block (add this to the END of every prompt)

> cute chibi game character, soft rounded shapes, big shiny eyes, bright pastel colors, fluffy texture,
> Roblox mobile game style, low poly friendly, full body, front three-quarter view, standing,
> plain white background, no text, no shadow on background, single character, centered

Tip: use the same image AI and the same style block for every picture so all characters match.
Use `Resources/../image.jpg` (your concept art) as a style reference if the AI allows image input.

## Before you use any image or model

- Check the AI tool's license allows **commercial use** (selling Robux items needs this).
- Record each asset in `Asset-Log.csv` (spec section 23.8).
- Do not ask for characters, names or styles copied from other games.
