# 3D model names

Save each model as `assets/models/<Name>.rbxm`, then run `build-place.bat` and open the rebuilt place.
Anything you don't add keeps its block-built version, so you can add models one at a time.

## How to save a model
1. In Studio, insert the model (Toolbox, your own model, or an imported `.fbx`/`.obj`).
2. Make it face **front = -Z**. In Studio that's the side the blue Move arrow points away from.
3. Right-click the model in Explorer, choose **Save to File...**, and save it into
   `E:\Monster-Garden\assets\models\` with the exact name below (for example `Cottage.rbxm`).
4. Size doesn't matter: the game scales every model to fit. Scripts inside models are removed.
